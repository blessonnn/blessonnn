## 💫 About Me

I'm a recent **B.Tech Computer Science** graduate based in Trivandrum, Kerala, specializing in **frontend development** and **UI/UX design**. I care about building clean, minimalist digital experiences that feel intentional rather than default — from custom-built portfolio interactions to full-stack applications with a machine-learning core.

Outside of code, I produce music and shoot minimal photography, both of which quietly shape how I think about interfaces: restraint, rhythm, and negative space.

```yaml
🔭 Currently Building:  A steganography tool (PixelVault) and a full-stack health-tech platform (VitalPulse)
🌱 Currently Exploring: Applied machine learning, AI-assisted UI workflows
🎯 Open To:             Frontend / UI-UX roles, freelance design-engineering collaborations
⚡ Fun Fact:            I design in Figma and finish the mix in a DAW on the same afternoon
```

## 🚀 Featured Projects

<details open>
<summary><b>🩺 VitalPulse — Health Monitoring & Disease Prediction System</b></summary>
<br/>

Bridges real-time IoT vitals (temperature, heart rate, SpO2) with patient-reported symptoms, using a Random Forest classifier to predict likely conditions and surface preliminary precautions. Features natural-language symptom extraction, vitals-aware dynamic symptom prioritization, and a glassmorphism-styled Streamlit patient portal.

| | |
|---|---|
| **Stack** | Python · Flask · Streamlit · scikit-learn · Pandas · Joblib |
| **Scale** | Trained on 4,920 patient records across 130+ symptoms |
| **Performance** | 100% accuracy on training dataset; sub-100ms API cold-start |
| **Architecture** | Decoupled Streamlit frontend ↔ Flask inference API ↔ Random Forest core |
| **Repository** | [Health_IoT_Project](https://github.com/blessonnn/Health_IoT_Project) |

Currently being extended with real-time ESP32 sensor integration and a persistent patient-history dashboard.

</details>

<details>

| | |
